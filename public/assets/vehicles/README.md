# Vehicle models

This folder contains the GLB exports from Kenney's Car Kit (CC0), plus the original `yellow-jeep-legacy.glb` used by Trekit.

Pick a vehicle model from this folder and update the model URL in `client/src/main.js`. The physics collider can be adjusted in the in-app **Jeep collider** panel.

The pack's license is retained in `LICENSE.txt`.
